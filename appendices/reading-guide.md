# 导读：沿一条设备链学习

本书以 ESP32 为起点，逐步扩展到嵌入式系统。目标是理解设备如何感知、处理、连接和行动，并能把一次成功的实验推进到有边界、能解释故障的小系统。

全书有四条互相交织的线：电路与能量、程序与状态、连接与数据、可靠性与验证。前六章是共同基础；第七至十四章讨论外设和网络；第十五至二十章讨论长期运行；第二十一至二十三章组成三个完整练习；第二十四章讨论系统扩展。

只想先观察的读者，可以先读第1、2、3章，再看三个项目的材料表和验收条件。准备动手的读者按顺序完成第4章串口、第5章按钮、第7章总线和第21章传感器，每一步留下日志再向后走。已经熟悉 MCU 的读者可以从并发、存储、安全和故障实验切入。

## 版本与实验边界

书内主要硬件是 ESP32-S3-DevKitC-1；基础 Arduino 示例按 3.x API 编写。其他芯片、开发板、模组和库版本需要重新核对，不能仅因名字含有 ESP32 就照抄引脚。官方 stable/latest 链接会滚动更新，运行时请记录完整工具链和库版本。

本版已进行文稿、路径、图文关系和示例的静态审查。未安装完整嵌入式工具链进行编译，也未在实物板卡上烧录、测量或验收；图示和计算中的假设均不作为实测结果。项目的验收步骤供读者在自己的硬件环境中逐项执行。

全书插图是原创教学图解。涉及连接的图优先表达电气和功能关系，面包板孔位、器件封装脚序、额定值与实际 PCB 仍以所选产品资料为准。练习限 USB 和低压直流，不涉及市电施工。

## 三个项目逐步组合什么

| 项目 | 输入与输出 | 新增加的能力 |
|---|---|---|
| 环境记录器 | BME280 → 串口 CSV | 单位、有效性、时间与数据记录 |
| 低压风扇控制器 | 温度 → MOSFET → 风扇 | 滞回、负载供电与故障策略 |
| 联网状态终端 | 局域网 JSON → OLED | 超时、字段检查、数据年龄与恢复 |

不必一次购买全部器材。第一轮只需板卡、数据线、LED、电阻和按钮；理解供电与上传后，再按项目添加传感器与屏幕。理论解释不依赖采购，也不以实现某个特定商品为阅读终点。
